# Architecture decision records

- `active/` contains decisions that still explain the current architecture.
  They provide rationale but are not behavioral specifications.
  Records marked `proposed` describe designs awaiting agreement and implementation.
- `history/` contains unmaintained historical records. They are non-normative
  and must not be used to determine current requirements or behavior.

Current behavioral requirements live in `openspec/specs/`.
User-facing behavior is documented under `website/`.
