Is RelayFold the right fit for you?

RelayFold may be a good fit if you need to:

  • Have a deterministic workflow with agentic steps?
  • Have rich API to manage the system and execution environment?
  • Resume after failure?
  • Understand what happened through state change events?
  • Verify AI agents are doing the right thing and self-correct?
  • Have full ownership over deployment environment?

If your answer is yes to these questions, RelayFold is for you!

Start locally with Docker.

The local install path uses a small wrapper and Docker Compose so users can easily try out RelayFold without complex setup.

curl -fsSL https://raw.githubusercontent.com/parsablelabs/relayfold/main/packaging/install.sh | sh
rf init --version 0.1.1
rf up

What starts

The generated local environment starts the orchestrator with SQLite backend, single worker services and creates local configuration under~/.relayfold.
